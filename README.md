# Haiyang Wang — Academic Portfolio

Source for [haiyangwang-1.github.io](https://haiyangwang-1.github.io), an academic portfolio and blog built with Astro.

## Local development

Requires Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

Create blog posts from `content-templates/blog-post.md` and save published posts under `src/content/posts/`.

## Production

```sh
npm run build
npm run preview
```

Pushes to `main` deploy through GitHub Pages.
